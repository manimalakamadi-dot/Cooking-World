# Cooking World 🍽️

A responsive restaurant website built using HTML, CSS, and JavaScript.

## Features
- Responsive restaurant design
- Food menu with images
- Food search and category filters
- Add to Cart functionality
- Half and Full quantity selection
- Cart total calculation
- Checkout and order bill
- Login and Signup pages

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Project Type
Frontend Restaurant Website
